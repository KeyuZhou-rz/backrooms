# Backrooms from the Ground Up

## Why This Project Was Born

Recently, I’ve become fascinated by computer graphics—especially how elegant, lightweight methods can produce astonishing visual effects. The workflow feels pure: open your laptop, picture what you want, work through the math, and translate it into code.

I’ve always been drawn to the concept of the Backrooms. It’s eerie how ordinary, mundane elements evoke such a visceral sense of discomfort once stitched together. Beyond the aesthetic, building this scene is great technical practice, and above all, genuinely fun. Life is too short to spend on side projects that are neither profitable nor enjoyable.

## How the Project Is Structured

This project serves primarily as a technical devlog to document how these effects come together from scratch. I don’t expect a massive audience, but I’d be thrilled if someone learns something useful or finds a spark of inspiration here. Thank you for reading and following along.

I plan to break down each effect step by step—not only for anyone following the log, but to solidify my own mental models along the way.

## Tutorials

- [Building Level 0](level0/level0.md): ray intersections, lighting, ceiling panels, and flicker.
- [Building the Poolrooms](swimming_pool/swimming_pool.md): the arch, tile seams, and simple moving water.

## Where Does the Code Come From?

As of October 2026, the base `webgl.js` setup is adapted from my Computer Graphics coursework under Professor Ken Perlin. All the shader code and scene logic are—and will continue to be—written entirely by me.

Because this is a hands-on learning project, I want to understand how every critical effect works under the hood and explain it in the most intuitive way possible. AI can churn out code and visual effects in seconds, but instead of handing over a black box that leaves you wondering *"Wait, how does that actually work?"*, I want to build and explain everything clearly from first principles.# backrooms
